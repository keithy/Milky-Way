Claude Code, Gemini Code, Pi-Agent — every AI coding tool runs on
bash. Bash is the integration plane.

The observation is that the integration plane is seventies technology,
and that this is the problem rather than the solution. Bash composes
by convention and by convention alone: no types, no schema, nothing that
can be checked before it runs.

Moldable development is the next generation of that plane — programmable,
inspectable and observable. The difference is not that it is more
capable but that it can be *examined*. A layer can be lifted off and
looked at, which is the difference between a system you operate and one
you merely hope about.
